# 打包说明（构建 Windows 安装包）

## 一、产物

运行 `pwsh -File _tools\build.ps1` 后，`dist\` 下会得到：

| 文件 | 大小 | 说明 |
|---|---|---|
| `AndroidVM-Setup-<ver>.exe` | ≈ 76 MB | NSIS 安装程序（可选安装目录、建桌面/开始菜单快捷方式） |
| `AndroidVM-Portable-<ver>.exe` | ≈ 75 MB | 免安装便携版，双击即用 |
| `win-unpacked\` | ≈ 175 MB | 解包目录，便于调试 |

安装包**只包含管理器本身**（Electron 运行时 + 应用代码 + 真机数据库），
**不包含 Android SDK**（17 GB）和 AVD 用户数据（15 GB）—— 这些太大，必须单独准备。

---

## 二、安装后的目录布局

### 便携版 / 解包版
```
AndroidVM.exe
AndroidVM\                 ← 数据根目录（首次运行自动创建）
├── android-sdk\           ← 需要你放进来，或改指向已有 SDK
├── avd\                   ← 虚拟机实例
├── _data\                 ← 实例注册表、真机库、档案
├── home\                  ← adb 密钥、临时文件
└── logs\                  ← 模拟器与补应用日志
```

### 安装版
装到 `C:\Users\<你>\AppData\Local\Programs\AndroidVM\`，
数据根目录同样在 `AndroidVM.exe` 同级的 `AndroidVM\` 下。

## 三、首次运行：SDK 怎么办

安装包不带 SDK，程序启动时会按下面顺序找：

1. 环境变量 `AVM_SDK_ROOT`
2. `_data\settings.json` 里保存的路径（界面上「选择已有 SDK」会写这里）
3. `<数据根>\android-sdk`
4. 环境变量 `ANDROID_SDK_ROOT` / `ANDROID_HOME`
5. `%LOCALAPPDATA%\Android\Sdk`

**如果都没找到**，界面顶部会出现橙色提示条，有两个按钮：

### 方式 A：在线下载（推荐，一键搞定）

点 **「在线下载 SDK（约 1.9 GB）」**，程序会：

1. 拉取 Google 官方仓库清单（`dl.google.com/android/repository/*.xml`）
2. 解析出各组件当前版本的 zip 地址、大小、SHA-1
3. 流式下载 → 校验 SHA-1 → 用系统自带 `bsdtar` 解压
4. 实时进度条显示当前文件与总体百分比

| 组件 | 下载大小 |
|---|---|
| `emulator` | ≈ 439 MB |
| `platform-tools` | ≈ 8 MB |
| `system-images;android-34;google_apis;x86_64` | ≈ 1491 MB |
| **合计** | **≈ 1.9 GB**（解压后 ≈ 5.4 GB） |

实测下载速度约 19 MB/s，全流程约 2 分钟（视网络而定）。
**不需要 Java / sdkmanager**，清单每次都重新解析，所以永远装最新版。

> 为什么 SDK 不放 GitHub？
> 解压后 5.4 GB，远超 GitHub 单文件 2 GB 限制，也不适合放进仓库或 Release。
> 官方源既没有体积限制，又始终是最新版本。

### 方式 B：选一个已有的 SDK

点 **「选择已有 SDK」**，选中包含 `emulator` 与 `platform-tools` 的目录
（例如 Android Studio 的 `%LOCALAPPDATA%\Android\Sdk`），保存后重启应用生效。

### 方式 C：手动准备

**手动复制**：把本项目的 `android-sdk\` 整个目录复制到 `<数据根>\android-sdk\`。

**用官方 sdkmanager**：
```powershell
sdkmanager "emulator" "platform-tools" "system-images;android-34;google_apis;x86_64"
```

**设环境变量**：
```powershell
$env:AVM_SDK_ROOT = "C:\Android\Sdk"
```

> 系统镜像必须装 `android-34` 的 `google_apis`（推荐）、`google_apis_playstore`
> 或 `google_atd`，否则切换镜像时会提示「镜像未安装」。

## 四、首次运行会自动做的事

1. 创建数据根目录（`avd` / `_data` / `home` / `logs`）
2. 从安装包的 `resources\seed\_data` 播种：
   - `supported_devices.csv`（Google Play 官方真机库，5.4 万台）
   - `profiles\`（预置真机档案）
   - 播种后写 `.seeded` 标记，之后不再重复复制
3. 首次启动实例时自动建 AVD 目录、分配端口 5554

## 五、构建环境注意事项（都踩过坑）

本机（非管理员）构建时有三个坑，`_tools\build.ps1` 已经全部处理：

| 问题 | 现象 | 处理 |
|---|---|---|
| `%TEMP%` 对子进程不可写 | electron-builder 报 `Access is denied`；NSIS 报 `!tempfile: Unable to create temporary file!` | 脚本把 `TEMP`/`TMP` 指到 `_cache\tmp` |
| Electron 下载缓存不可写 | `open ...\electron\Cache\xxx.zip: Access is denied` | 设 `ELECTRON_CACHE` 到项目内，并用 `electronDist` 指向本地已装的 Electron |
| 非管理员无法建符号链接 | 解压 `winCodeSign` 时 `Cannot create symbolic link` | `package.json` 设 `signAndEditExecutable:false` 跳过内置 rcedit，改由 `build/afterPack.js` 调 `build/rcedit-x64.exe` 写图标和版本信息 |
| `ELECTRON_RUN_AS_NODE=1` | electron 以纯 Node 模式运行，`require('electron')` 返回路径字符串 | 脚本里清空该变量 |

### 关于代码签名

**当前产物未签名**。Windows 首次运行会弹 SmartScreen「已保护你的电脑」，
点「更多信息 → 仍要运行」即可。

要正式签名需要买代码签名证书，然后在 `package.json` 的 `win` 里配置：
```json
"certificateFile": "path/to/cert.pfx",
"certificatePassword": "***"
```
并去掉 `signAndEditExecutable: false`（那样就需要管理员权限来解压 winCodeSign）。

## 六、重新打包

```powershell
# 一键构建（自动处理环境变量、缺依赖自动装、缺图标自动生成）
pwsh -File _tools\build.ps1

# 只解包不生成安装程序（快，适合调试）
cd app
npm run dist:dir
```

改版本号：编辑 `app\package.json` 的 `version`，产物文件名会自动跟着变。

---

## 七、卸载

- 安装版：设置 → 应用 → Android 14 虚拟机管理器 → 卸载
- 卸载**不会**删除数据根目录（AVD 与配置保留），需要彻底清理时手动删
  `%LOCALAPPDATA%\Programs\AndroidVM\AndroidVM\`
- 便携版：直接删 exe 和同级的 `AndroidVM\` 目录
